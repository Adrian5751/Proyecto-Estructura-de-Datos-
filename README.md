# Proyecto-Estructura-de-Datos-
Adrian Jesus Pelaez Rodriguez

El objetivo principal es comprender cómo funcionan internamente estas estructuras, cómo se manejan la memoria, los índices, el crecimiento dinámico y el enlace entre elementos, además de aplicar buenas prácticas como el uso de genéricos, la separación entre interfaz e implementación y el manejo controlado de errores.


El proyecto está formado por varios archivos organizados de la siguiente forma. El archivo Lista.java contiene la interfaz genérica que define los métodos que toda lista debe implementar. El archivo Nodo.java contiene la clase que representa un nodo individual, utilizada únicamente por la lista enlazada. El archivo ArrayList.java contiene la implementación basada en un arreglo dinámico. El archivo ListaEnlazada.java contiene la implementación basada en nodos enlazados. El archivo Main.java contiene todos los casos de prueba, tanto positivos como de error. Finalmente, este archivo README.md documenta el funcionamiento general del proyecto.


La interfaz Lista define el contrato que deben cumplir las dos implementaciones. El uso del parámetro genérico E permite que la lista pueda almacenar cualquier tipo de dato, ya sea entero, cadena, objeto, etcétera, sin tener que duplicar el código. Los métodos definidos en la interfaz son: add que añade un elemento al final de la lista; add con índice que añade un elemento en una posición específica; remove que elimina el elemento ubicado en una posición y lo devuelve; get que devuelve el elemento ubicado en una posición sin eliminarlo; size que devuelve la cantidad de elementos almacenados; clear que elimina todos los elementos dejando la lista vacía; y isEmpty que indica si la lista no contiene elementos.


La clase Nodo es la pieza fundamental de la lista enlazada. Cada nodo almacena un dato de tipo E en el atributo dato, y guarda una referencia al siguiente nodo de la cadena en el atributo link. Si el atributo link vale null, significa que ese nodo es el último de la lista. La clase incluye un constructor que recibe el dato a guardar y coloca automáticamente el enlace en null, dejando el nodo listo para ser enlazado posteriormente cuando la lista lo necesite.

La clase ArrayList implementa la interfaz Lista utilizando internamente un arreglo de objetos llamado items. Además, mantiene dos atributos enteros: size, que representa el número actual de elementos almacenados, y capacity, que indica la capacidad máxima del arreglo antes de necesitar crecer. El constructor inicializa el arreglo con una capacidad de diez posiciones, coloca el tamaño en cero y deja la lista lista para usarse.

El método privado expand se encarga de aumentar la capacidad del arreglo cuando ya no hay espacio. Para ello crea un nuevo arreglo más grande con diez posiciones adicionales, copia todos los elementos existentes con un bucle for, actualiza el valor de capacity y reemplaza el arreglo antiguo por el nuevo. Este método se llama automáticamente desde los dos métodos add cuando el arreglo está lleno.

El método add sin índice verifica primero si el arreglo está lleno comparando size con capacity; si lo está, llama a expand, y luego coloca el nuevo elemento en la primera posición libre e incrementa el tamaño. El método add con índice valida que la posición sea correcta, expande si es necesario y luego desplaza todos los elementos desde el final hacia la derecha para hacer espacio en la posición indicada, coloca el nuevo elemento y aumenta el tamaño. El método remove valida la posición, guarda el elemento a eliminar para devolverlo, desplaza los elementos siguientes hacia la izquierda para cubrir el hueco, reduce el tamaño y devuelve el elemento eliminado. Si la posición no es válida, el método devuelve null en lugar de lanzar una excepción, lo cual es una forma sencilla de manejar el error. El método get valida la posición y devuelve directamente el elemento almacenado en esa posición del arreglo, o null si la posición es inválida. Finalmente, size devuelve la cantidad de elementos, clear reinicia el arreglo a su estado original de diez posiciones y isEmpty comprueba si el tamaño es cero.


La clase ListaEnlazada implementa la interfaz Lista utilizando nodos enlazados. Mantiene dos atributos: primero, que apunta al primer nodo de la cadena o vale null si la lista está vacía, y size, que lleva la cuenta de cuántos nodos hay. El constructor simplemente inicializa ambos atributos en null y cero respectivamente.

El método add sin índice crea un nuevo nodo. Si la lista está vacía, ese nodo se convierte en el primero. Si no, recorre la lista con un nodo auxiliar llamado temp hasta llegar al último nodo, y enlaza el nuevo nodo al final asignando el link del último nodo al nuevo. Después incrementa el tamaño. El método add con índice valida la posición. Si la posición es cero, inserta el nuevo nodo al inicio, haciendo que apunte al antiguo primer nodo y actualizando primero. En caso contrario, recorre la lista hasta el nodo anterior a la posición deseada, enlaza el nuevo nodo con el que estaba en esa posición, y actualiza el enlace del nodo anterior para que apunte al nuevo. Finalmente incrementa el tamaño.

El método remove valida la posición. Si se elimina el primero, guarda su dato y actualiza primero para que apunte al segundo nodo. Si se elimina otro, recorre la lista hasta el nodo anterior al que se quiere eliminar, guarda el nodo a eliminar y actualiza el enlace del nodo anterior para que se salte el nodo eliminado. Reduce el tamaño y devuelve el dato guardado. Si la posición no es válida, el método devuelve null. El método get valida la posición, recorre la lista con un nodo auxiliar hasta llegar a la posición indicada y devuelve el dato almacenado en ese nodo, o null si la posición es inválida. Los métodos size, clear y isEmpty funcionan de forma similar a los de la lista basada en arreglo: devuelven la cantidad, reinician primero a null junto con el tamaño, y comprueban si el tamaño es cero.


El archivo Main.java contiene una serie de casos de prueba organizados en dos bloques: uno para ArrayList y otro para ListaEnlazada. Cada bloque incluye casos positivos y casos de error.

En los casos positivos se prueba que al agregar elementos a la lista y luego obtenerlos por su índice se devuelve el valor esperado, y que al eliminar un elemento se devuelve el valor eliminado. En el caso del ArrayList se agregan las cadenas A y B, se obtiene el elemento en la posición cero y se elimina el elemento en la posición uno. En el caso de la ListaEnlazada se agregan las cadenas X y Y, se obtiene el elemento en la posición cero y se elimina el elemento en la posición uno. Estas pruebas demuestran que ambas estructuras funcionan correctamente en su uso básico.

En los casos de error se prueba qué ocurre cuando se intenta obtener un elemento con una posición fuera de rango. Como las implementaciones devuelven null en lugar de lanzar una excepción, el programa imprime null en la consola, demostrando que el error fue manejado de forma controlada y que el programa no se detuvo de forma abrupta. Esta decisión de diseño hace que el código sea más sencillo y fácil de usar, aunque sacrifica un poco de información sobre la causa exacta del error.


Este proyecto permite comprender de forma práctica la diferencia entre una lista basada en arreglo y una lista basada en nodos enlazados. La primera ofrece acceso rápido por índice pero necesita redimensionarse cuando se llena; la segunda crece de forma natural pero requiere recorrer los nodos para acceder a una posición. Además, el uso de una interfaz común permite tratar ambas implementaciones de la misma forma, aplicando polimorfismo, y el manejo de errores mediante valores null garantiza que el programa no falle abruptamente ante situaciones inesperadas.
